## What this is

Staydesk is a lightweight motel management app for a single small property (~10-15 rooms). MVP modules: guest management (reservations, check-in/out, folio), Stripe payments, and Gusto payroll integration. Auth is Supabase. Single-tenant — one property, no multi-tenancy.

## Commands

**Backend** (run from `backend/`):
```bash
./gradlew bootRun                        # dev server (port 8080)
./gradlew test                           # all tests
./gradlew test --tests "com.staydesk.*ClassName*"  # single test class
./gradlew build                          # build jar
```
Gradle wrapper (`gradlew`) is generated by running `gradle wrapper` once after installing Gradle.

**Frontend** (run from `frontend/`):
```bash
npm run dev      # Vite dev server
npm run build    # production build
npm run preview  # preview production build
```
No linter or test runner is configured yet.

## Architecture

```
backend/   — Spring Boot 3.5, Java 21
frontend/  — React 19, Vite, react-router-dom v7
docs/      — planning notes and decisions log
```

**Backend** (`com.staydesk`): Spring Boot REST API with Spring Security, Spring Data JPA, Spring Validation, and Lombok. PostgreSQL 15 is the database. Schema is managed exclusively via Flyway migrations in `backend/src/main/resources/db/migration/` — `spring.jpa.hibernate.ddl-auto=validate` means JPA never modifies the schema; all DDL changes require a new Flyway migration file.

**Frontend** (`frontend/src/`): React 19 SPA organized as `components/`, `pages/`, `api/`, `hooks/`, `utils/`, `assets/`. HTTP calls go through `axios` in the `api/` layer.

**Auth flow**: Supabase handles authentication. The Spring Security layer should validate Supabase-issued JWTs on protected endpoints.

**External integrations**:
- Stripe (`stripe-java` 25.3.0) — payment capture and webhooks
- Gusto (`https://api.gusto.com`) — payroll sync via OAuth client credentials
- Supabase — auth only (not used as a database)

## Environment variables

All secrets are injected via environment variables. For local development, create `backend/src/main/resources/application-local.properties` (gitignored):

```
DATABASE_URL=jdbc:postgresql://localhost:5432/staydesk
DATABASE_USERNAME=...
DATABASE_PASSWORD=...
STRIPE_API_KEY=...
STRIPE_WEBHOOK_SECRET=...
GUSTO_CLIENT_ID=...
GUSTO_CLIENT_SECRET=...
```
