# Daily Opening Checklist

Complete this checklist at the start of every shift before assisting guests.

---

## System check

- [ ] Log in to StayDesk and confirm the dashboard loads correctly.
- [ ] Review today's calendar for check-ins expected today.
- [ ] Review today's calendar for check-outs due today (standard check-out: 11:00 AM).
- [ ] Confirm any reservations arriving today show **Confirmed** status.

---

## Arrivals review

- [ ] Pull up each expected arrival and verify the room assignment.
- [ ] Confirm each arrival room is marked clean and ready.
- [ ] Note any special requests or notes on the reservation.

---

## Departures review

- [ ] Identify all guests checking out today (green blocks on calendar).
- [ ] Confirm each folio is accurate — no missing charges, no duplicate entries.
- [ ] Flag any folios with questions to the manager before the guest arrives at the desk.

---

## Front desk readiness

- [ ] Receipt printer is online and has paper.
- [ ] Key cards / keys are stocked and programmed for today's arrivals.
- [ ] Any messages or notes from the previous shift have been reviewed.

---

## Handoff from overnight (if applicable)

- [ ] Review any notes left by the overnight shift.
- [ ] Confirm no outstanding payment issues from overnight check-ins.
- [ ] Confirm room status is current — any rooms cleaned overnight are updated.
