# Front Desk Quick Reference

*Print and keep at the desk. For full instructions see the training guides.*

---

## Check-In (guest arriving)

1. Find reservation on calendar → click block
2. Verify guest ID
3. Click **Check In** → **Confirm Check-In**
4. Issue room key
5. Remind guest: check-out is **11:00 AM**, card charged at check-out

**Walk-in?** → New Reservation → fill details → Save → then Check In

---

## Check-Out (guest departing)

1. Find green block on calendar → click block
2. Review folio — confirm all charges correct
3. Click **Check Out** → **Confirm & Charge**
4. Collect room key
5. Notify housekeeping

**Card declined?** → Ask for alternate payment → Call manager if unresolved

---

## New Reservation

1. Click **New Reservation** (top-right)
2. Enter: name, phone, check-in/out dates, room, # guests
3. Review total
4. Click **Save Reservation**

---

## Common situations

| Situation | Action |
|-----------|--------|
| Guest locked out | Verify name against reservation → issue replacement key |
| Guest requests late check-out | Check availability → manager approval required past 1 PM |
| Guest wants receipt | Open completed reservation → print from browser |
| No-show guest | Do **not** cancel — flag to manager |
| System down | Use paper log → call manager |

---

## Key times

| Event | Time |
|-------|------|
| Standard check-in | 3:00 PM |
| Standard check-out | 11:00 AM |
| Late check-out limit (no fee) | 1:00 PM (manager approval) |

---

## Escalate to manager when...

- Payment is declined and guest has no alternate card
- Guest is disputing a charge
- A reservation needs to be cancelled or modified after check-in
- You are unsure about anything — **when in doubt, ask**

---

*Emergency? — Call 911 first, then the manager.*
